# Image Speech
## Intro
Vibecoded Python Script that takes what you say and presents an image of your choosing in a window to capture in OBS Virtual Camera to act as a replacement for a webcam (cause I don't have a webcam)
## Directions
Make sure Python is installed
Get a Vosk model and name the folder it came in to "Vosk" and make sure its in the same Directory as main.py
Run the main.py file
